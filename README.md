# Projet_Informatique_Application_Mobile
Application mobile React Native pour suivre les randonnées en temps réel avec Firebase (auth, carte, photos, GPS).
 Fonctionnalités de l'application Suivi de Randonnée
1. Page d’accueil
Deux boutons :

Connexion

Inscription

2. Authentification avec Firebase
Utilisation de Firebase Auth

Fonctionnalités :

Connexion par email + mot de passe

Inscription avec :

Email

Mot de passe

Nom

Prénom

Âge

3. Accès après connexion
Redirection vers une page de suivi

Un bouton : “Commencer mon randonnée”

4. Suivi de randonnée
Lorsqu’on clique sur “Démarrer le suivi” :

Affichage d’une carte interactive

Suivi du chemin en temps réel

Affichage d’une ligne de parcours

Enregistrement de points GPS dans Firebase

Deux boutons disponibles :

 Arrêter

 Prendre une photo

5.  Fin de randonnée
Une fois que l’utilisateur appuie sur “Arrêter”, l’application affiche :

Distance parcourue

Durée
